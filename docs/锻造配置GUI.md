# 锻造配置 GUI

支持文件 `etc/upgrade_separate.etc`。通过通用工具菜单“强化/增幅/锻造 → 锻造配置”，或该文件的 GUI 模式进入；两个入口共用文件草稿。

- 锻造等级：每级读取 `[table]` 的 4 项，顺序为属性系数 A、属性系数 B、成功率、材料倍率。成功率分母为 10000，GUI 按百分比编辑，精度 0.01%。前两个系数只读。
- 最大等级：编辑 `[separate upgrade max]`，允许范围为 1 到已有锻造表的行数。不会自动增加锻造表，也不会改写 `[level]` 或特效等配套数据。
- 材料消耗：`[item weights by grade]` 与 `[item weights by grade 100lv]` 分页显示，每条为装备等级、材料 ID、数量基数。道具名称从归档物品索引解析，未找到时显示 ID。
- 批量设置：锻造页聚合成功率和材料倍率；材料页聚合材料 ID 和数量基数。使用双端滑块或数字框选择范围，仅更新勾选项。
- 其他参数：折叠区只读展示 `[level]`、稀有度权重、武器权重、特效与其他数值参数，暂不推定未知字段的含义。

材料数量展示的是基数，不是游戏内最终消耗。`100lv` 表的选择条件、稀有度位置映射与取整规则尚未确认，GUI 不计算最终消耗。

数值编辑保留源文件整数/浮点类型；源字段是整数时拒绝写入小数材料倍率。成功率按整数万分比保存。编辑保留未修改字段、注释和换行格式；文件或归档发生变化后需重新打开表单。

点击“应用到草稿”后，再点击“保存锻造”写入工作区，最后保存 PVF 写入归档。
